# Easy Trail Mountaineering Website

A website developed for **Easy Trail Mountaineering** to showcase its products, services, and business information. Built using HTML and CSS as part of an academic project.

## Coding Language Used
- HTML
- CSS

## Purpose
To provide the local business Easy Trail Mountaineering with an online webpage presence, promote its products and services, and help potential customers contact and learn more about the business.

## Disclaimer
Developed as an academic project by students of Bukidnon State University.
